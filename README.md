# J2Dex

J2Dex es una aplicación móvil desarrollada con **Ionic, Angular y Capacitor**, que permite consultar información de Pokémon mediante una API. El proyecto incluye funcionalidades de búsqueda, visualización de información, reproducción de sonidos, galería de imágenes y comparación de personajes.

## Descarga de la aplicación

La aplicación se encuentra publicada en itch.io:

[**Descargar J2Dex**](https://justpaladin.itch.io/j2dex)

## Tecnologías utilizadas

- **Ionic Framework 8:** desarrollo de la interfaz móvil.
- **Angular 18:** estructura y lógica de la aplicación.
- **Capacitor 6:** integración y generación de la aplicación para Android.
- **TypeScript:** desarrollo de la lógica.
- **PokéAPI:** obtención de información de los Pokémon.
- **Android Studio:** compilación del proyecto para Android.

## Instalación en un dispositivo Android

1. Descargar el APK desde la página de itch.io.
2. Transferir el archivo al dispositivo Android, si fuera necesario.
3. Abrir el archivo APK desde el dispositivo.
4. Seguir las indicaciones de instalación de Android.
